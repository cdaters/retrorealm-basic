# RetroRealm BASIC Computer 0.7.0 — public beta · beta1

Open `index.html` in a current browser. Choose an original example, type RUN, or start a blank program. No web server, account, framework or network is required. The complete HTML guide is in `manual/index.html`; beta/privacy/feedback information is in `manual/about.html`.

Use the selected language profile deliberately. Tiny BASIC, Microsoft 8K, Simple Web Basic and TRS-80 Level II are compatibility subsets, not complete historical machines. Normal arrow keys edit the command; Up/Down recalls commands. EDIT retrieves numbered lines; Escape cancels edits. The source editor has explicit Apply/Cancel. STOP pauses; CONT resumes. Fullscreen/focus view and three phosphor themes are available.

Export programs, workspaces and virtual media separately before clearing storage or closing a tab. A workspace stores source, profile and seed, not a running execution snapshot. Virtual cassette records are not physical tape images. The Worker and finite budgets remain enforced.

Only original examples are included. Import source you are entitled to use. No historical game packages or third-party interpreter are bundled.
