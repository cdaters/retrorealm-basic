Beta, privacy & feedback

Version 0.7.0 · build split1-review. Prepared for owner approval; this preview is not yet an authorized public release. Apache-2.0 is proposed, not applied.

What works

Write, edit and run numbered BASIC, use command history and a multiline source editor, import and export programs/workspaces, and explore bounded virtual media. Seven original examples and four compatibility subsets are included. The standalone Computer works offline; Grav integration is optional.

Known limitations

This is not full hardware emulation. Historical numeric precision, RNG, display controls, ROMs and physical cassette encoding differ. No immediate expression execution or portable running-program snapshot is provided. Unsupported syntax reports a diagnostic. Browser storage on file URLs varies; export important work. Execution and storage limits remain enforced. Read the profile chapters before importing source.

Automated desktop and mobile-viewport checks are distinct from human screen-reader and physical-touch testing. Those practical checks remain an owner acceptance item for this beta.

Your privacy

The Computer has no telemetry or external service. Program text, input, seeds and virtual media stay in this browser unless you choose to export/share them. Workspaces can be saved in local browser storage; virtual media lives in the open tab until exported. Imports do not run automatically. Browser extensions and other same-origin software are outside this boundary.

When hosted on a website, ordinary page/asset requests reach that website and may appear in its access logs. The host may use its own theme preferences, cookies or privacy policy. Offline use makes no third-party network requests.

Useful feedback

Record the build, browser/OS, language profile, terminal width, exact error and BASIC line, and a minimal original program that reproduces the issue. Add the seed and steps if randomness matters. Share only source you have permission to share; remove personal data, private programs and credentials from screenshots or exports.

No public issue tracker or feedback endpoint is enabled in this approval build. The owner will choose a contact channel before public launch. Do not post security-sensitive details publicly; use a designated private contact when one is announced.
