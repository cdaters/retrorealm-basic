Commands, compatibility & limits
Use NEW, LIST, EDIT n, RUN, STOP, CONT and HELP. EDIT 5 loads the complete line into the input: Enter commits, Escape cancels. Keep its line number; that number alone deletes it. Retrieving/canceling never changes execution state or random numbers. Committing discards continuation, just like numbered replacement. The latest LIST supports line-selection shortcuts for up to 256 lines; larger listings remain available through EDIT n. Type 10 PRINT "HELLO" to insert/replace a line, or 10 to delete it. Outside a line edit, Up/Down recalls commands; Tab leaves the input. At INPUT your text is program data; use the Stop button or Ctrl-C to interrupt. Clear screen only clears display.
Supported: PRINT, INPUT, assignments, IF/THEN/ELSE, GOTO, GOSUB/RETURN, ON GOTO/GOSUB, FOR/NEXT, DIM, DATA/READ/RESTORE, DEF FN, strings, math and seeded RND. Immediate-mode expressions are not yet supported.
Simple Web Basic supports full, case-sensitive identifiers such as LANDTRADE, preserves INPUT case, and uses plain numeric output. Choose this profile for compatible modern source; dialects are never auto-switched. It is a bounded compatibility subset with BASIC Lab’s seeded RNG, not a complete clone. Tiny uses truncated integer arithmetic and RND(n) in 1…n. MS/TRS subsets use JavaScript double precision, not historical floating point. TRS-80 supports DEFINT and typed variables, implicit THEN, CLS, cassette typed records and a sequential OPEN/CLOSE extension. Exact MEM/POKE, ROM tape encoding and machine floating point remain unsupported. Physical multiline source records require explicit recovery; imports never rewrite them. BBC BASIC is a future target. The profiles are compatibility experiments, not machine emulators.
Per run: one million instructions and expression evaluations, two seconds active VM time, 128 KiB output, 16,384 array cells, 4,096 characters per string and 128 stack frames. Input wait time is excluded. A safety stop ends the run; CONT cannot bypass these limits. Source is limited to 128 KiB characters / 4,096 lines. A Worker watchdog cancels unresponsive execution.
All interpretation is local. No network, server filesystem, BASIC JavaScript evaluation or telemetry. Historical listings are not included in this environment.
